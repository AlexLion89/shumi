# Книжная полка Вики — правила для работы

- **Начинать с замечаний Вики:** `node tools/feedback.mjs` (открытые), ответ — `reply|done <id> "текст"`;
  ответ виден у неё в приложении, `done` закрывает issue-уведомление в shumi-data. Её данные (`shelf.json`,
  `feedback/`) личные: читать, чтобы понять замечание; полку без её просьбы не править.
- **Не делать новое вслепую.** Сначала посмотреть, чем она пользуется (`git pull` в `../shumi-data`: книги, замечания),
  и идти от её замечаний. Идеи на потом — `IDEAS.md`.
- **Cloudflare в пути к её телефону не ставить:** с её мобильного он почти не отвечает (замеры 24.10.2026:
  0–2 из 6, через Гонконг). Работает: GitHub Pages, GitHub API, FantLab, Open Library, обложки LitRes.
- **Node 22:** `C:\out\node22\node.exe` по полному пути; системный Node 16 не трогать.
- **Перед пушем:** `node --test tests/*.test.mjs` и `node tools/ui-check.mjs` (headless Edge, около 3 минут).
  С ключом (`~/.shumi-dev-token`, только с разрешения владельца): `tools/e2e-github.mjs` (временный файл в
  shumi-data), `tools/live-check.mjs` (живой сайт; запись в GitHub браузер отклоняет — без этого приложение само дописывает
  полке страницы, так было 25.10.2026), `tools/update-check.mjs` (кнопка «Обновить»), `tools/e2e-share.mjs` (ссылка на итоги через shumi-share и Pages).
- **Новое поле книги или замечания — только с умолчанием при чтении:** у неё на телефоне и в shelf.json лежат
  записи старого вида.
- **Файлы — только LF**, коммиты — от `AlexLion89 <sirenyov@gmail.com>` (глобальная подпись git на машине — рабочая).
- **Выкладка** — пуш в `main`: тесты, Pages (версия в `sw.js`), Worker. У Вики новая версия — по кнопке «Обновить».
