# shumi — книжная полка

Приложение для телефона: «Читаю», «Прочитано», «Хочу прочитать», оценки и итоги года.
Адрес — https://shumi.sirenyov.link.

Устройство: приложение — GitHub Pages (`site/`), данные и поиск — Cloudflare Worker с D1 и KV (`worker/`).
Ресурсы Cloudflare создаёт задание `.github/workflows/cloudflare-setup.yml`.
