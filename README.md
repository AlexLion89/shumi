# shumi — книжная полка

Приложение для телефона: «Читаю», «Прочитано» по годам со звёздами на книжных полках, «Хочу прочитать»,
итоги года с картинкой для сторис, замечания разработчику (💬). Адрес — https://shumi.sirenyov.link
(ставится на экран «Домой» из Safari). Правила работы — `CLAUDE.md`, идеи на потом — `IDEAS.md`.

## Как устроено

- **Приложение** — статика на GitHub Pages (`site/`), без сборки: ES-модули.
- **Полка** — файл `shelf.json` в приватном репозитории `AlexLion89/shumi-data`. Телефон читает и пишет его
  через GitHub API (`site/github.js`); каждое изменение — коммит с понятным сообщением, история репозитория —
  резервная копия. Копия полки и очередь неотправленных правок лежат на телефоне (`site/sync.js`), поэтому
  приложение открывается и работает без сети; правки с двух устройств не затирают друг друга.
- **Вход** — токен GitHub с доступом только к `shumi-data` (Contents: чтение и запись), вводится один раз.
- **Поиск** — FantLab, Google Книги и Open Library прямо с телефона (`site/sources.js`, порядок выдачи — `site/rank.js`);
  LitRes (русские книги и аудиокниги) и Douban (китайские книги с оригинальными обложками) — через посредника.
  Каталоги выбираются по письменности запроса: кириллица, латиница, иероглифы. Ключ Google Books — в `config.json`
  shumi-data (ограничен сайтом и Books API), телефон читает его после входа.
- **Посредник** — функция `shumi-proxy` в Yandex Cloud (`proxy/`, каталог `shumi` облака владельца): у LitRes и Douban
  нет CORS, обложки Douban грузятся только со своим Referer. Пересылает лишь адреса из короткого списка, ничего не
  хранит; не больше двух экземпляров одновременно. Выкладка — `node tools/proxy-deploy.mjs` (yc, профиль `shumi`).
- **Аудиокнига** — в карточке книги из «Хочу» и «Читаю»: точная ссылка на LitRes с чтецом и поиск в Яндекс Книгах.
- **Замечания** — `feedback/<id>.json` в shumi-data (`site/feedback.js`); ответ — `node tools/feedback.mjs`.
  Новое замечание заводит issue в shumi-data (задание `feedback.yml` там) — GitHub присылает уведомление.
- **Копии обложек и таблица** — задание `backup.yml` в shumi-data (скрипт `tools/backup.mjs`): `covers/<id>.jpg`,
  `shelf.csv` — после каждого изменения полки и в 04:00 МСК. Копии нужны и картинке «Итоги года».
- **Новая версия** — плашка «Вышла новая версия · Обновить» (Service Worker ждёт нажатия).
- **Ссылка на итоги для подруг** — итоги года шифруются (`site/seal.js`, AES-GCM) и лежат в публичном
  `AlexLion89/shumi-share` на GitHub Pages; ключ — только в ссылке `shumi.sirenyov.link/y/#<id>.<ключ>`, страница —
  `site/y/`. Какие ссылки созданы — `shares.json` в shumi-data. Ключу приложения нужен доступ и к shumi-share.
- **Обложки** — адреса каталогов или фото из приложения (`repo:covers/<id>.jpg?v=…` — в shumi-data); смена — в
  карточке книги (другие издания FantLab, поиск по названию, фото).
- **Cloudflare не используется:** с мобильного интернета Вики он почти не отвечает (замеры 24.10.2026: 0–2 из 6).
  Worker `shumi-api` (`worker/`) остался от этапа 0 — поиск LitRes и замеры связи; приложению не нужен.

## Разработка и проверки

Нужен Node 22+ (на машине владельца — `C:\out\node22\node.exe`).

```bash
node --test tests/*.test.mjs       # данные полки, отправка в GitHub (заглушка с настоящими кодами ответов), поиск
node tools/ui-check.mjs            # путь Вики в headless Edge: найти → «Хочу» / «Прочитала» → коммит; снимки экранов
node tools/dev.mjs                 # http://localhost:8760/?gh=http://localhost:8788&token=t — демо-полка, заглушка GitHub

# с настоящим ключом (файл с токеном; значение никуда не выводится)
SHUMI_TOKEN_FILE=~/.shumi-dev-token node tools/e2e-github.mjs   # два «устройства» пишут во временный файл shumi-data, потом он удаляется
SHUMI_TOKEN_FILE=~/.shumi-dev-token node tools/live-check.mjs    # живой сайт читает полку (только чтение)
```

Выкладка — пуш в `main`: GitHub Actions гоняет тесты, выкладывает сайт на Pages (подставляет версию в `sw.js`)
и Worker. Посредник выкладывается отдельно, с машины владельца: `node tools/proxy-deploy.mjs`. Иконки — из `art/raccoon.png`: `python tools/icons.py`.
