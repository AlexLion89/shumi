# Идеи на потом

Записано 25.10.2026 (ночь, МСК). Порядок — от более полезного к менее. **Делать по её замечаниям**, а не вслепую:
на 25.10.2026 у неё 2 книги и 0 замечаний.

| Идея | Что это | Когда делать |
|---|---|---|
| Ссылка на итоги года для подруг | Страница только для чтения с мозаикой года — без ключа, со случайным адресом; отзывается | Если картинки для сторис мало и попросит ссылку |
| Сменить обложку | В карточке: другие издания с FantLab (`/work/{id}/extended` — с CORS) или фото с камеры (уменьшить на canvas → `covers/<id>.jpg` в shumi-data) | Если пожалуется на «корешки» без обложек или не те обложки |
| LitRes в поиске | Русский нон-фикшн и селф-хелп есть только там; API без CORS — нужен посредник не на Cloudflare: бесплатная функция Yandex Cloud | Если напишет «не нашлась книга», а FantLab и Open Library её не знают |
| Страницы за год | У Open Library есть `number_of_pages_median`, у FantLab нет; показывать «≈ N страниц», где известны | Если спросит |
| Сортировка «Хочу» | Сейчас — новые сверху; по автору или названию | Когда список станет длинным |
| Убрать Cloudflare | Worker `shumi-api`, D1 и KV не нужны приложению (этап 0) | Когда точно не вернёмся к LitRes через Worker |
