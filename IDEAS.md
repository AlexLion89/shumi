## LitRes в поиске — выбрать способ

Русский нон-фикшн и селф-хелп («Магия утра», «Кафе на краю земли») есть только у LitRes. Его API браузер к себе не
пускает (нет CORS) — нужен посредник, причём не на Cloudflare (у Вики с мобильного он почти не отвечает).
Проверено 25.10.2026: Читай-город пускает браузер, но требует гостевой ключ из куки своего сайта — хрупко;
Google Books пускает браузер (CORS с нашего адреса), но общая квота без ключа исчерпана.

| Способ | Что сделать владельцу | Плюсы | Минусы |
|---|---|---|---|
| **A. Google Books со своим ключом** | Google Cloud → проект → включить Books API → ключ, ограниченный сайтом `shumi.sirenyov.link/*` и Books API (минут 5) | Без сервера, бесплатно (1000 запросов в сутки), запросы прямо с телефона | Покрытие русского нон-фикшна не проверено — проверить на её запросах, когда будет ключ; обложки мелкие |
| **B. LitRes через функцию Yandex Cloud** | Аккаунт Yandex Cloud с платёжным аккаунтом (бесплатный уровень — 1 млн вызовов в месяц), сервисный аккаунт для выкладки | Покрытие LitRes проверено, хорошие обложки; российская инфраструктура — с мобильного должна отвечать | Свой код посредника (~30 строк), ещё одна платформа и ключ для выкладки |
| C. Российский VPS | ~200 ₽ в месяц | Всё в своих руках | Деньги и обслуживание ради одного поиска |

Предложение: сначала A (дёшево попробовать), замерить её запросы; если русского нон-фикшна не хватит — B.
